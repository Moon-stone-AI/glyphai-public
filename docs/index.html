How it works

Five sources, one language

The logs already sit on the servers being sold. We read them before decommissioning, translate every vendor's wording into one set of concepts, and tie each event to a GPU by its PCIe address. Nothing is installed on the servers; the tool reads copied files, offline.

What moves the score

What it is not

Stated limits

  • History, not a forecast. The score describes what happened to a card. It is not a probability that the card will survive a given time.
  • Tested on synthetic fleets. Real logs differ; each new fleet starts with tuning its vocabulary.
  • Starting weights. Set from operations practice and to be calibrated on real failure data.
  • No logs, no history. A card whose logs were wiped can only be graded by testing.
